# 技法与病相

## 一、改稿教训

这些是从反复批改中长出来的经验，比任何定义都直接。

**意象要有空间逻辑。** 前句「月如钩」是仰视，后句「一星如豆」仍在同一片夜空，两个意象争夺视线，必须换掉一个。远近、高低、内外要有秩序，读者的眼睛才不会乱撞。

**古诗词一字一词，不套白话结构。** 「并肩数过星三两颗」十个字十个词，是现代口语节奏；「并肩曾指星河浅」七言压到四词密度，才是诗。砍掉连接词、量词、进行时态。

**不直接报情感状态。** 「人渐远，信全疏」六个字在喊「我们疏远了」，是通讯录备注不是词；「春易老，约成虚」不说人，说春天与约定，反而更重。

**五绝是减法中的减法。** 二十字，每个字要做三个人的活。不要过渡句，不要解释，结尾必须是最凝练的画面——「一僧归月峰」，二十字到此为止。

**韵脚先定，句随韵生。** 反过来做，一定凑字。先选出三到五个同部韵脚，再让句子向它们生长。

**对仗避合掌，一联之内意象不重复。** 「神州」对「华夏」、「五湖」对「四海」都是同义反复；上句写月、下句仍写月，是浪费一联。

## 二、炼字三法

动词炼字。名词靠动词活。「春风又绿江南岸」的「绿」是形容词动用，「红杏枝头春意闹」的「闹」是通感。写景时把「有」「是」全部换成具体动作：横、卧、挂、垂、泻、铺、压、挑、卷。

通感。打通两种感官，颜色可有温度，声音可有重量。「色寒」「香冷」「声脆而薄」都是这个路子。用一次是点睛，用三次是油滑。

虚实互换。把抽象写成具体，把具体写成抽象。「愁」是虚，写成「一江春水」是实；「白发三千丈」把实写成虚，反而更真。

## 三、意象

意象不是装饰，是情感的物质形态。常用意象的稳定含义：月主思乡与孤寂，柳主离别（柳留同音），雁主书信与远行，水主时光与愁绪，云主漂泊与隐逸，雨主愁与阻隔，黄昏主迟暮，砧声主秋思与征人，灯主独处与守候，舟主行役与归心，阑干主凭眺与待人不至。

三条铁律：一句之内意象不超过两个；同一首内意象不可互相打架（写了月亮就别让星星抢戏）；一首只立一个主意象，其余服从它。

空间逻辑单列：近景与远景、仰视与俯视、室内与室外，三种关系每句只能推进一种。若两句在同一视点写同类物象，删掉较弱的一句。

## 四、意境三层

第一层写景，只写所见：「明月松间照，清泉石上流」。第二层情景交融，景带情绪：「感时花溅泪，恨别鸟惊心」。第三层象外之象，画外有人格：「孤舟蓑笠翁，独钓寒江雪」——钓的不是鱼。

营造五法：以动衬静（鸟鸣山更幽）、以乐景写哀（春光大好而人不在）、以小见大（一粒沙里见世界）、虚实相生（眼前景与记忆交叠）、留白（不说尽，让读者补）。

三层不必强求。硬拔到第三层，往往变成故作高深。写住第一层的准确，胜过第三层的伪深刻。

## 五、化用

取前人诗意而注入自己的情境，与抄袭的分界在「有没有新境」。三法：化句（改字易境）、化意（取其事不取其辞）、化境（取其气象，另铸新词）。

三条避坑：不照抄原句超过四字；一首之内不超过两处；化用后应让人「似曾相识」而非「一眼认出」。若读者立刻想起原句而想不起你的句子，这次化用就失败了。

## 六、病相自查表

| 病名 | 症状 | 治法 |
|---|---|---|
| 辞藻堆砌 | 金玉锦绣满纸而无一事可指 | 删掉全部形容词，改用动词重写 |
| 意象拥挤 | 一句塞进月、柳、雁三样 | 一句留一到两个，其余移位或删 |
| 意象打架 | 月与星同片夜空，雨与晴光并存 | 统一时空，保留主意象 |
| 直报情感 | 「人渐远，信全疏」 | 化为物象：「春易老，约成虚」 |
| 白话入古 | 「并肩数过星三两颗」 | 压缩语法：「并肩曾指星河浅」 |
| 形容词依赖 | 每句都有华美修饰 | 用细节动作替换 |
| 假情 | 辞藻华丽而无一事可指 | 回到真实经验，宁可写小事 |
| 结尾说理 | 末句总结、升华、点题 | 换成画面或问句，说完就停 |
| 合掌 | 对仗两句同义 | 换一句写另一面 |
| 凑韵 | 韵脚字与句意不合 | 换韵部或换句，不可将就 |
| 三平尾 | 句末三字全平 | 改第三字为仄 |
| 伪古风 | 「殇」「浅唱」「陌上」「流年」 | 换成可触摸之物，或直接删 |

机器写诗的通病是过度匀称：每句都通顺，每联都工整，读完全篇记不住一句。人写的诗总有一处硌手——一个不漂亮的词、一次突兀的跳跃、一个过分具体的数字。那一处才是人的痕迹。

## 七、经典语料

不是套用的模板，是校准语感的标尺。

写景欲开阔，读「星垂平野阔，月涌大江流」；欲清冷，读「鸡声茅店月，人迹板桥霜」。写情欲深，读「此情可待成追忆，只是当时已惘然」；欲淡，读「人生若只如初见，何事秋风悲画扇」。写愁欲重，读「梧桐更兼细雨，到黄昏、点点滴滴」；欲轻，读「一川烟草，满城风絮，梅子黄时雨」。写志欲壮，读「长风破浪会有时，直挂云帆济沧海」；欲孤，读「不要人夸颜色好，只留清气满乾坤」。

读时注意句长与停顿：五言沉，七言畅，词的长句宜铺叙，短句宜顿挫。语感靠读音养，不靠背名句清单。
